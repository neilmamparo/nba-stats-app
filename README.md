# NBA Stats App

## Overview

NBA Player Stats is a Java application that retrieves NBA player statistics for a selected season. It uses basketball APIs to display players and their main statistical averages, making it easier to explore and compare player performance.

## Features

- Select an NBA season.

- Retrieve NBA player statistics through APIs.

- Display players and their main statistical averages.

## Tools & Technologies

- Java – Application logic and data processing.

- balldontlie API + API-NBA – NBA player and statistical data.

## How It Works

The application retrieves data from two APIs for the selected season and player. It processes the information and aggregates the data to display players alongside their main statistical averages. This provides a quick and easy way to explore statistics for players across many seasons.
