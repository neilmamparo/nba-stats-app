## NBA Stats App

# Overview

NBA Player Stats is a Java application that retrieves NBA player statistics for a selected season. It uses basketball APIs to display players and their main statistical averages, making it easier to explore and compare player performance.

# Features

Select an NBA season.

Retrieve NBA player statistics through APIs.

Display players and their main statistical averages.

Explore player performance across seasons.

# Tools & Technologies

Java – Application logic and data processing.

balldontlie API – NBA player and statistical data.

NBA-API – Access to additional NBA statistics.

# How It Works

The application retrieves data from its APIs for the selected season. It processes the information and displays players alongside their main statistical averages. This provides a simple way to view NBA statistics without manually searching for each player.
